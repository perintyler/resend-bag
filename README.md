# Resend (Barry Pack)

Email sending, inbox management, and spam filtering via Resend.

## Tools

- `send_email` — send an email with optional CC, BCC, reply-to, and file attachments
- `email_status` — check email service configuration status
- `list_emails` — list inbox emails with pagination and read/spam filters
- `read_email` — read the full body of an email
- `search_emails` — search emails by keyword
- `mark_email_read` — mark an email as read
- `delete_email` — delete an email
- `reply_email` — reply to an email
- `forward_email` — forward an email
- `list_spam_senders` — list blocked spam sender patterns
- `add_spam_sender` — add a spam sender pattern
- `remove_spam_sender` — remove a spam sender pattern
- `mark_as_spam` — mark an email as spam
